# OpenMV / Raspberry Pi 视觉通信协议

## 当前接线版本

本版按照用户接线图更新后，PA2/PA3 已用于 8 路循迹 S1/S2，因此不再使用 USART2。

视觉通信预留到：

```text
PA9  -> USART1_TX
PA10 -> USART1_RX
波特率：115200，8N1
```

视觉端连接方式：

```text
OpenMV/RPi TX -> STM32 PA10 USART1_RX
OpenMV/RPi RX -> STM32 PA9  USART1_TX
GND           -> STM32 GND
```

注意：USART1 同时也用于调试打印。如果视觉端已经接到 PA9/PA10，不建议再同时接 USB-TTL 调试器。正式视觉模式下建议减少或关闭周期性调试打印。

## 消息格式

视觉端发送 ASCII 行：

```text
$T,<x_err>,<y_err>,<valid>\n
```

示例：

```text
$T,-32,18,1
```

含义：

| 字段 | 说明 |
|---|---|
| x_err | 目标中心相对画面中心的水平偏差，左负右正 |
| y_err | 目标中心相对画面中心的垂直偏差，上负下正，具体可按视觉端定义调整 |
| valid | 1 表示识别到目标，0 表示目标丢失 |

## 后续建议

如果你要同时保留调试串口和视觉串口，建议二选一：

1. 将 8 路循迹模块改成 I2C/串口读取，释放 PA2/PA3，再恢复 USART2；
2. 使用 STM32 的其他可用串口/软串口方案，但要重新核对与 PWM、编码器、循迹引脚的冲突。
