# 调参建议

## 1. 循迹 PID

初始参数：

```c
#define LINE_BASE_PWM       360
#define LINE_PID_KP         0.18f
#define LINE_PID_KI         0.00f
#define LINE_PID_KD         0.035f
```

调参顺序：

1. `KI` 保持 0；
2. 先调 `LINE_BASE_PWM`，确保直线能稳定慢速行驶；
3. 增大 `KP`，让小车能明显修正偏差；
4. 如果弯道来回摆动，适当增加 `KD`；
5. 如果过弯冲出，降低基础速度或降低输出限幅；
6. 稳定后再考虑速度闭环。

## 2. 丢线策略

当前逻辑：

- 没有任何传感器检测到黑线时，按最后一次有效误差方向原地搜索；
- `TRACKER_LOST_SEARCH_PWM` 控制搜索速度。

如果赛道宽、弯道大，可以把原地搜索改为“低速前进 + 偏转”。

## 3. 8 路权重

默认权重：

```text
-3500, -2500, -1500, -500, 500, 1500, 2500, 3500
```

权重越大，纠偏越激进。车速越快，通常需要更平滑的权重和更强的 D 项抑制摆动。

## 4. 编码器速度闭环

当前工程先保留编码器采样，不默认启用速度闭环。建议在开环循迹能跑稳后再加速度内环，否则问题定位会变复杂。
