## 3. 分模块接线详图

### 3.1 电机驱动 — TB6612FNGVM

```
   STM32                            TB6612FNGVM
  ┌──────┐                        ┌──────────────┐
  │      │                        │              │
  │ PB12 ├────────────────────────▶ AIN1         │
  │ PB13 ├────────────────────────▶ AIN2         │       ┌─────────┐
  │      │                        │              ├───────┤ 左电机   │
  │ PB14 ├────────────────────────▶ BIN1         │       └─────────┘
  │ PB15 ├────────────────────────▶ BIN2         │
  │      │                        │              │       ┌─────────┐
  │ PA9  ├────────────────────────▶ PWMA         ├───────┤ 右电机   │
  │ PA8  ├────────────────────────▶ PWMB         │       └─────────┘
  │      │                        │              │
  │      │                        │ STBY ──┬─────│ (接3.3V高电平使能)
  │      │                        │ VM ────╪─────│ 12V 电池
  │      │                        │ VCC ───╪─────│ 3.3V
  │      │                        │ GND ───╪─────│ GND
  └──────┘                        └──────────────┘
```

**方向控制逻辑:**

| 状态 | AIN1 (PB12) | AIN2 (PB13) | BIN1 (PB14) | BIN2 (PB15) |
|------|-------------|-------------|-------------|-------------|
| 前进 | 0 | 1 | 1 | 0 |
| 后退 | 1 | 0 | 0 | 1 |
| 停止 | 0 | 0 | 0 | 0 |

PWM 频率: **1 kHz** (TIM1, ARR=999, PSC=71)，占空比范围 0~1000

```
  ┌──────────┐                ┌──────────┐

  │ Channel B├────────────────▶ PA1/TIM2_CH2 │
  │ VCC      ├────── 3.3V ────┤ VDD       │

  │ VCC      ├────── 3.3V ────┤ VDD       │
  │ GND      ├────── GND ─────┤ GND       │
  └──────────┘                └──────────┘
```

### 3.3 循迹传感器 — 8路数字量输入

```
  循迹传感器阵列 (从左到右 8 路)
  ┌────────────────────────────────────────────────────────────┐
  │  X1      X2      X3      X4      X5      X6      X7      X8 │
  │  左 ←─────────────────── 中间 ──────────────────────→ 右   │
  └──┬───────┬───────┬───────┬───────┬───────┬───────┬───────┬──┘
     │       │       │       │       │       │       │       │
     ▼       ▼       ▼       ▼       ▼       ▼       ▼       ▼
    PB11    PB10    PB1     PB0     PA7     PA6     PA5     PA4

  权重值:   -7      -5      -3      -1      +1      +3      +5      +7
```

- **低电平有效** (LINE_LEVEL = 0): 黑线 = 低电平，白色 = 高电平
- 所有引脚 **内部上拉** 使能，默认高电平
- `TRACK_LOST = 127` 表示所有传感器均未检测到线

### 3.4 调试串口 — USART2

```
  USB转TTL模块                   STM32
  ┌──────────────┐           ┌──────────┐
  │ TX ──────────┼──────────▶│ PA3 (RX) │
  │ RX ──────────┼──────────◀│ PA2 (TX) │
  │ GND ─────────┼───────────│ GND      │
  └──────────────┘           └──────────┘
```

- 参数: **9600 baud, 8N1, 无流控**
- 用途: `printf` 调试输出

### 3.5 系统时钟与控制定时器

| 功能 | 引脚 | 说明 |
|------|------|------|
| HSE 晶振 | OSC_IN / OSC_OUT | 8 MHz 外部晶振 → PLL 倍频到 72 MHz |
| 控制定时器 | TIM3 (无外部引脚) | 10ms 控制周期中断 (ARR=999, PSC=719) |
| 阻塞延时 | SysTick (无外部引脚) | HCLK/8 = 9MHz 时基 |

## 5. 引脚冲突提醒

| 占用引脚 | 当前用途 | 冲突外设 |
|----------|----------|----------|
| PA4 ~ PA7 | 循迹 X5 ~ X8 | SPI1 (NSS / SCK / MISO / MOSI) |
| PB6 / PB7 | 右编码器 | I2C1 (SCL / SDA) |
| PB10 / PB11 | 循迹 X1 / X2 | USART3 / I2C2 |
| PB12 ~ PB15 | 电机方向控制 | SPI2 |
| PA9 | 左电机 PWM | USART1_TX |
