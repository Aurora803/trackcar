# 校赛循迹实车测试报告

## 1. 测试目的

验证 `school-competition-line-v1` 在矩形赛道上的连续运行稳定性，确认循迹底盘是否可以冻结用于校赛展示，并记录状态机实际恢复行为和证据边界。

## 2. 测试平台

- 控制器：STM32F103C8T6；
- 电机驱动：TB6612FNG；
- 路径检测：8 路数字循迹传感器；
- 转角辅助：编码器累计；
- 控制方式：开环 PWM 底盘 + 位置误差纯 P 循迹；
- 调试/启停：USART2 9600 8N1，蓝牙 `START/STOP` 或 `1/0`。

实物电池型号、测试场地尺寸、赛道线宽、传感器安装高度和测试日期未在仓库资料中完整记录，需由测试人员补充。

## 3. 稳定参数

```c
#define LINE_CORNER_ENCODER_TARGET      495
#define LINE_RECOVER_CORRECTION_LIMIT   40
#define LINE_RECOVER_PWM                200
#define LINE_RECOVER_CENTER_CONFIRM_MS  250U
```

编码器角点退出条件：

```c
g_corner_encoder_sum >= LINE_CORNER_ENCODER_TARGET
```

## 4. 测试条件

- 使用参数 495 的同一稳定版本；
- 连续运行过程中不修改参数；
- 以现场观察确认车辆是否完成矩形循迹；
- 串口工具用于辅助观察状态，但只保存了部分尾部数据。

由于完整测试环境参数未留档，本报告不补写赛道尺寸、电池电压或地面材质等未知信息。

## 5. 单圈与多圈测试

本轮提交依据是连续 5 圈耐久测试。已有现场观察确认车辆能够逐圈完成矩形循迹。仓库现有材料没有形成可逐项引用的单圈独立日志表，因此不虚构每圈用时、角点数量或逐圈故障统计。

## 6. 连续 5 圈耐久测试

- 现场连续完成 5 圈矩形赛道运行；
- 5 圈全程未修改参数；
- 车辆能够持续完成循迹与角点恢复；
- 串口日志工具仅保存部分尾部状态记录，不能写成“完整串口日志证明了 20 个角点”。

可采用的准确表述为：

> 经现场连续5圈实车耐久测试验证，车辆能够完成矩形循迹运行；现有串口文件保存了部分尾部状态记录。

## 7. 状态机运行分析

实车角点处理并不总是从 `CORNER` 直接进入 `FOLLOW`。常见链路为：

```text
FOLLOW --TR=2--> CORNER --TR=7--> BLIND --TR=8--> RECOVER --TR=10--> FOLLOW
```

其中 `TR=2` 表示识别角点，`TR=7` 表示角点阶段转入丢线搜索，`TR=8` 表示重新捕线进入恢复，`TR=10` 表示中心稳定后回到正常循迹。

部分情况下出现：

```text
RECOVER --TR=11--> BLIND
```

随后仍可通过 `TR=8` 和 `TR=10` 重新恢复。这属于当前容错路径的一部分，不应描述成所有角点都沿最短理想链路运行。

## 8. 丢线与恢复表现

角点后主要依靠 `BLIND` 搜索与 `RECOVER` 中心确认重新捕获中心线。`LINE_RECOVER_CORRECTION_LIMIT=40`、`LINE_RECOVER_PWM=200` 和 250 ms 中心连续确认共同约束恢复阶段。现场结果表明容错机制可以支撑连续 5 圈运行。

准确评价为：角点后容错恢复机制能够有效重新捕获中心线，当前版本满足校赛展示稳定性要求，但仍存在恢复路径偏长的优化空间。

## 9. 当前结论

1. `LINE_CORNER_ENCODER_TARGET=495` 的版本已通过现场连续 5 圈实车耐久测试；
2. 测试全程参数保持不变；
3. 当前版本适合冻结用于校赛展示；
4. 当前不再修改循迹核心参数、状态机、引脚和底层配置；
5. 现有部分尾部日志只能辅助说明状态行为，完整 5 圈结论以现场观察为依据。

## 10. 已知不足

- 个别角点后的恢复路径较长；
- `RECOVER` 可能短暂以 `TR=11` 返回 `BLIND`；
- 左编码器历史观测不稳定，未启用速度闭环；
- 底盘仍采用开环 PWM；
- 完整串口原始日志、逐圈用时和完整环境记录未保存；
- 视觉识别、二维云台及底盘通信尚未完成联调。

## 11. 校赛展示建议

- 展示使用 `school-competition-line-v1` 冻结版本，不现场改循迹核心参数；
- 展示前检查电池、接线、传感器高度、轮胎和烧录版本；
- 保留蓝牙 `1/0` 用于清晰启停；
- 正式拍摄完整连续运行视频，并尽量同步保存从启动到停止的完整串口日志；
- 后续先完成视觉云台独立验收，再做最小接口联调，避免影响已冻结底盘。
